#  Customer Churn Prediction – Telecom Capstone Project

##  Problem Statement
You are a Data Scientist at a telecom company named **Leo**. The company is facing a churn issue—customers are leaving for competitors. Your task is to analyze customer data, identify key churn indicators, and develop a predictive model that helps the business retain customers.

## 🎯 Objectives
- Analyze customer behavior and patterns to understand churn.
- Identify important features that influence churn.
- Build a machine learning model to predict customer churn.
- Help business teams proactively target customers at risk.

##  Dataset
The dataset contains customer demographics, account information, service usage, and churn status.

>  *Note:* Make sure the dataset is placed in the appropriate path or updated in the notebook before running.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Scikit-learn
- TensorFlow / Keras (for deep learning)
- Jupyter Notebook

##  Key Steps
1. **Data Cleaning & Preprocessing** – Handled missing values, categorical encoding, and scaling.
2. **Exploratory Data Analysis** – Visualized patterns and distributions of churned vs. non-churned users.
3. **Model Building** – Used deep learning (Sequential model with Dense layers) for classification.
4. **Evaluation** – Assessed model performance using accuracy and classification metrics.

## How to Run
1. Clone this repository or download the notebook file.
2. Place the dataset in the same directory.
3. Launch the notebook using Jupyter Notebook or Google Colab.
4. Run all cells to preprocess, train, and evaluate the mode
